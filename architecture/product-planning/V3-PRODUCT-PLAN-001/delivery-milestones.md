# Proposed incremental milestones

Every milestone is PROPOSED; no dates, scope approval or automatic release authorization.

| Milestone | Increment | Required evidence/authority before claiming it |
| --- | --- | --- |
| M0 | Requirement ownership and decision questions agreed | A-001, explicit product review; this plan not approved by authoring |
| M1 | Customer/access/search and minimum cross-cutting criteria ready | A-002/003/007/A-017 and required security/failure policy dispositions; no code |
| M2 | Independent design/isolated domain increment | Approved pure-domain or UX scope, exact exclusions; no live Tenant claims |
| M3 | Trusted runtime foundations eligible for product reliance | Applicable mechanism decisions, AUTH/IAM scope, real-path remediation and explicit G-RUNTIME disposition; no inherited lab acceptance |
| M4 | First synthetic Customer vertical slice | H-001 with approved contracts, Audit and safe health; not general FIRST_RELEASE completion |
| M5 | Platform and five business journeys integrated | H-002, each approved mapping/Report Set/resource attachment; provider/consumer/real-integration evidence |
| M6 | Security/product acceptance submission | I-002, findings and per-profile criteria; explicit distinct authority dispositions |
| M7 | Profile readiness dossiers | J-001/002/003: Shared, Managed, Sovereign each independently evidenced; OD-015/023 and custody resolved as applicable |
| M8 | First Release decision and separately authorized release | J-004, all mandatory evidence and explicit Level 4 readiness plus execution approval |

M2 design work need not wait for M3. M4 does not remove any of the fifteen capabilities or three profiles from the first supported production release. Sovereign-local authority is an approved target obligation, not permission to activate offline continuation. Full Air Gap is a separate pending commitment.
