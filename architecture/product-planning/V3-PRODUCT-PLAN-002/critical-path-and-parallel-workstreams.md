# Critical path and parallel execution — proposed

Sequence numbers in the table are an acyclic display order, not a finish-to-start mandate beyond named prerequisites. Each non-parent execution still needs explicit scoped permission. No estimate of elapsed time, team size or calendar dates is invented.

## Critical path to Customer CM-1

Selected A-002/A-003/A-007/A-013/A-015 requirements and A-017 policies → C-001/E-000/K-001 contract boundaries and applicable B decisions → C-003/004/005 + D-004/005/006 → D-002 actual-path roll-up → D-003 submission **AND explicit satisfactory G-RUNTIME decision** → F-BJ-001/002 + E-003/K-002 + G-004 → H-001 and I-003 artifact-bound evidence. F-000/G-003/E-001 may advance independently only within explicitly approved non-live scope and exclusions. Conditional K-003/eligibility/quota paths join only when approved selection requires them.

No claim that this entire critical path is approved or that real Runtime reliance is safe now. D-001 and authority must determine accepted-path/Gate applicability first. IAM remediation implementation may proceed before final Gate only with its own exact authorization and required controls; no product runtime clearance from that fact.
